# wavemesh_485_read_open

WaveMesh 6 路 RS-485 采集接收脚本 `survey485read` 的公开版本信息仓。

功能简介：工控机接收 6 路 324 字节秒级帧，电压按 `/100` 解析为毫伏。电流 / 压降 / 温度分别用不同 MQTT DID 上传，库名与表名可配置。测量字段 `DECIMAL(7,3)`。采集设置窗口最大宽度 500，保存走后台线程。关于页「检查更新」读取本仓版本号。

本仓只放版本元数据，不提供 APK、安装包或脚本文件。

当前版本：**1.6.1**（2026-10-12）

- 清单：`survey485read.json`
- 标签：`survey485read-1.6.1`
